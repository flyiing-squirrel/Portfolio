# RMR 레시피 전처리 정리

[프로젝트 상세로 돌아가기](../rmr-recipe-db.md)

프로젝트에서 수행한 재료 분류와 표준화 과정을 정리했습니다.

| 작업 | 처리 목적 | 수행한 내용 |
| --- | --- | --- |
| 식재료·양념 분리 | 용도별 재료 비교 | 레시피의 재료를 식재료와 양념으로 구분 |
| 계량 단위 표준화 | 사용량 비교 | 서로 다른 사용량 표현을 g 기준으로 정리 |
| 재료명 매핑 | 같은 재료의 표현 통일 | 문장 임베딩과 코사인 유사도 임계값을 활용해 국가 식품 표준 명칭에 대응 |

대상은 기존에 수집된 비정형 레시피 17만 건입니다. 정제된 데이터베이스의 AWS RDS(MySQL) 배포는 팀 결과물입니다.
