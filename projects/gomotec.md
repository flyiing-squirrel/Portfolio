# AI 자세 추정 기반 표준작업지도서

> 제조 현장의 작업 영상을 자세 추정으로 분석하고, 그 결과를 영상·다국어 안내를 갖춘 웹 표준작업지도서에 연결했습니다.

[포트폴리오로 돌아가기](../README.md) · [GitHub](https://github.com/nneans/gomotec) · [작업지도서 보기](https://gomotec.vercel.app/)

| --- | --- |

| 프로젝트 | 고모텍 청년 일경험 프로젝트 |
| 역할 | 팀 팔레트 팀장 |
| 분석 대상 | 버터플라이 밸브 제조 공정의 현장 작업 영상 |
| 주요 기술 | YOLO Pose, ONNX Runtime Web, HTML, CSS, JavaScript |
| 결과물 | 영상·다국어 지원 웹 표준작업지도서 |

## 1. 문제와 목표

제조 공정을 표준화하려면 작업 순서와 실제 동작을 함께 확인할 수 있어야 합니다. 현장 영상을 분석해 표준 작업 절차를 정의하고, 작업 영상과 관련 정보를 한 화면에서 볼 수 있는 웹 작업지도서를 만드는 것이 목표였습니다.

분석 결과를 현장 사용으로 이어가기 위해 공정별 작업 순서뿐 아니라 부품, 치공구, 검사, 환경·안전 정보를 함께 제공했습니다.

## 2. 담당 역할

- **팀 운영과 기업 소통:** 팀장으로 기업 담당자 미팅을 진행하고 팀 활동을 조율했습니다.
- **현장 데이터 수집:** 제조 현장을 방문해 공정 작업 영상을 수집했습니다.
- **작업 동작 분석:** YOLO 자세 추정 모델로 관절 키포인트를 추출하고 작업자 움직임을 분석했습니다.
- **표준 절차 정의:** 동작 분석 내용을 표준 작업 절차를 정의하는 데 활용했습니다.

웹 화면의 세부 기능과 배포 구조는 아래에 팀 결과물로 소개합니다.

## 3. 영상에서 작업지도서까지

```mermaid
flowchart LR
    A[현장 공정 영상] --> B[YOLO 관절 키포인트 추출]
    B --> C[작업자 동작 분석]
    C --> D[표준 작업 절차 정의]
    D --> E[영상 연동 웹 작업지도서]
```

현재 공개 저장소의 분석 모듈은 YOLO11n Pose의 ONNX 모델을 브라우저에서 실행합니다. 키포인트 위치의 변화로 동작량을 계산하고, 동작량을 이용해 활동·저동작 구간을 구분합니다. 구간별 몸통·상완 각도 등의 요약 정보와 영상 간 비교 결과도 제공합니다.

자동 검출된 구간에는 기본 단계명이 적용되며, 관리자가 이를 실제 공정에 맞게 조정할 수 있습니다.

## 4. 팀 결과물

| 기능 | 구현 내용 |
| --- | --- |
| 공정별 안내 | 몸체수압검사, 가조립, 레디알, 총조립, 최종수압검사 **5개 공정** |
| 영상 연동 | 작업 영상과 단계 게이지 연동 |
| 작업 정보 | 작업 순서, **22개 부품** 정보, 치공구·장비, 검사, 환경·안전 정보 |
| 다국어 안내 | 한국어·영어·네팔어 **3개 언어** 전환 |
| 모바일 작업자 화면 | 작업 순서와 검사 기준을 스마트폰에서 확인 |
| 분석 운영 | 관리자 화면에서 Pose 분석, 영상별 결과 내보내기 및 재사용 |

관리자는 공정 영상을 등록하고 자세 분석을 실행한 뒤 단계명을 확정합니다. 작업자는 웹이나 모바일에서 해당 단계의 영상과 작업 절차를 확인할 수 있습니다. 팀은 운영 매뉴얼을 전달하고 GitHub 저장소와 Vercel 배포를 고모텍 측에 이관했습니다.

현장 피드백에서는 종이 작업지도서와 비교한 실용성을 긍정적으로 평가받았습니다.

## 5. 데이터 분석 관점에서의 의미

**관절 좌표를 이용한 동작 분석을 실제 작업 절차에 연결**했습니다. 영상 수집부터 분석과 절차 정의, 현장에서 확인할 수 있는 화면까지 이어지는 과정을 경험했습니다.

팀장 역할에서는 기업의 요구와 팀의 작업 내용을 맞추고, 결과물을 현장에서 이해할 수 있는 형태로 전달하는 일을 맡았습니다.
